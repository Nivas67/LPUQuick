# LPUQuick — Full-Stack Quick-Commerce Application

A Calm Commerce quick-delivery web application built for LPU campus delivery, featuring the exact Stitch UI/UX design specifications, Node.js + Express backend, SQLite database, WebSocket live order tracking, and Flow Assist AI.

## 🚀 Features

- **8 Pixel-Perfect Screens**: Sign In/Up, Home, Categories, Cart, Checkout, Flow Assist AI, Orders & Tracking, and Settings.
- **Dynamic Home Screen Engine**: Time-aware backend serving "Morning Essentials", "Lunch Prep", "Afternoon Pick-Me-Up", "Evening Snacks", and "Midnight Cravings" automatically.
- **Flow Assist AI**: Natural language intent parser creating bundle recommendations within budget.
- **Inventory & Smart Substitutions**: Typo-tolerant search with automatic alternatives for out-of-stock items.
- **Transparent Cart Pricing**: Real-time itemized calculation (Subtotal, Delivery Fee, Platform Fee, GST) with a free delivery progress bar.
- **1-Tap Checkout & Slide-to-Pay**: Gesture-driven slider with UPI intent link generation and 200ms screen shake error handling.
- **Live Order Tracking**: WebSocket live GPS simulation of rider movements and milestone progress.

## 🛠️ Quick Start

```bash
# Clone the repository
git clone https://github.com/Nivas67/LPUQuick.git
cd LPUQuick

# Install dependencies
npm install

# Run the app
npm start
# Open http://localhost:3000 in your browser
```
